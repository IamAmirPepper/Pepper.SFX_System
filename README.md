# SFX System

A simple, modular sound effects system for Unity.

## How to install
1. Make sure Git is installed beforehand
2. Create Unity 6000.0 (or later) project.
3. In Unity, open **Window → Package Manager**.
4. Click the **+** button → “Add package from git URL”.
5. Paste: `https://github.com/IamAmirPepper/Pepper.SFX_System.git`
6. **Optional It is possible to add the DLLs to the Assets folder, there you should be able to find A guide and manual**
7. To do so:
8. Tools -> SFX System -> Install to Assets.
9. Alternatively, download them from: `https://github.com/IamAmirPepper/Pepper.SFX_System/tree/main/Documentation~`
10. Or download them from: `https://github.com/IamAmirPepper/Pepper.SFX_System/releases`
